# Example: animated slime

Generated by EasyPixel from an MCP client (the way Claude would do it): `create_sprite`, one
`draw_grid` per frame, `create_animation` and `export_godot`. Validated in Godot 4.5.1.

![Animated slime](slime.gif)

| File | Contents |
|---|---|
| `slime.epx.json` | Editable EasyPixel project (open it with *File → Open*) |
| `slime.png` | 216×24 spritesheet: 9 frames of 24×24 in one row (`hframes=9`) |
| `slime.tres` | `SpriteFrames`: `idle` (frames 0–3, 160 ms, looping) and `jump` (frames 4–8, no loop) |
| `slime.tscn` | `AnimatedSprite2D` with nearest filtering and `idle` autoplay |
| `slime.gif` | Preview (8×) assembled from `slime.png` |

The `.tres`/`.tscn` paths point to `res://sprites/slime/`: copy the folder there in your project
(or re-export from EasyPixel to any folder you like).
